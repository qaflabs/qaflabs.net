# Qaf Labs — logo kit

The mark is two shapes: a square (ink) and a circle (vermilion) that touch at a single point.
The square has three rounded corners; the one sharp corner is where it meets the circle.
The circle has the same area as the square.

## Files

| Folder | File | Use |
| --- | --- | --- |
| `svg/` | `qaf-labs-logo.svg` | Primary logo (mark + name) on light backgrounds |
| `svg/` | `qaf-labs-logo-on-dark.svg` | Primary logo on dark backgrounds |
| `svg/` | `qaf-labs-logo-black.svg` / `-white.svg` | One-colour versions (print, stamps, embossing) |
| `svg/` | `qaf-labs-mark.svg` / `-on-dark.svg` | Mark alone, full colour |
| `svg/` | `qaf-labs-mark-black.svg` / `-white.svg` | Mark alone, one colour |
| `svg/` | `qaf-labs-app-icon-vermilion.svg` | App icon (primary), full-bleed square |
| `svg/` | `qaf-labs-app-icon-dark.svg` | App icon (alternate), full-bleed square |
| `svg/` | `qaf-labs-avatar.svg` | Round avatar for social profiles |
| `png/` | `*.png` | High-resolution raster copies of the above |
| `favicon/` | `favicon.svg`, `favicon.ico`, `favicon-16…512.png` | Browser tab, bookmarks, home-screen icon |

App icons are full-bleed squares: iOS and Android apply their own rounded mask.

## Colour

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#0B0B0F` | Logo, text, dark backgrounds |
| Paper | `#F6F5F1` | Light backgrounds |
| Vermilion | `#FF4A1C` | The circle, app-icon background, accents. Never for body text. |

## Typeface

The name is set in Geist SemiBold (free, Google Fonts), outlined in the SVGs so no font is needed.

## Rules

- Clear space: keep at least the height of the circle empty around the logo.
- Minimum size: logo 16 px tall on screen; mark 16 px.
- Keep the square and circle touching at one point. Don't separate, rotate, recolour or add effects to them.
- On vermilion backgrounds, use the ink square with a white circle (see the vermilion app icon).
